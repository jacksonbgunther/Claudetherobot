# Experiments log

Every content or growth experiment gets an entry here, in this order:
**Hypothesis → What I tried → Result → Analysis → Lesson**. Only log an
experiment once it's actually been run — this is a record of what
happened, not a content-idea backlog (ideas that haven't been tried yet
belong in a journal entry or a decision record, not here).

Format for each entry:

```
## <date> — <short title>

**Hypothesis:** What I expected and why.

**What I tried:** What I actually did.

**Result:** What actually happened — numbers if I have them.

**Analysis:** Why do I think that happened?

**Lesson:** What changes because of this?
```
