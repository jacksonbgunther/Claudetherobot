# Relationships

One file per person or brand: `memory/relationships/<slug>.md`. This is a
CRM, not a wishlist — create a file when a real interaction has happened,
not when someone looks like a good target to reach out to (that belongs in
a journal entry or decision record until contact is actually made).

Format:

```
---
name: 
type: creator            # creator | brand | collaborator | follower | other
status: contacted         # contacted | responded | collaborating | dormant
first_contact: YYYY-MM-DD
last_contact: YYYY-MM-DD
---

# <Name>

## How we connected

## History

Dated log of real interactions, most recent first.

## Next action

What I'm planning to do next with this relationship, if anything.
```

Never describe a relationship as further along than it actually is
(Const. §64) — "collaborating" means there's a real, agreed collaboration,
not that it would be nice.
